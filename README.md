make a 3D game similar to doors on Roblox. add rooms that go up to room 200. add yellow room indicators that say the room. but dont make them say U-XX. for example, room 5 is U-5, room 34 is U-34, etc. add tables and lockers that you can hide in. use these images for reference abt what the rooms look like. make it so the rooms randomly generate to be 1 of the 5 room types. try to make the rooms be identical to the references
